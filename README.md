# 🏥 Hospital Appointment Booking System

A web-based application to manage hospital appointments using Java, JSP, Servlets, Hibernate, and MySQL.

---

## 🚀 Live Demo
https://hospital-appointment-booking-system-tbk4.onrender.com

---

## 📌 Features
- 👨‍💼 Admin: Manage departments, doctors, and appointments  
- 👨‍⚕️ Doctor: View and manage appointments  
- 🧑 Patient: Register, login, and book appointments  

---

## 🛠️ Tech Stack
- Java, JSP, Servlets  
- Hibernate ORM  
- MySQL  
- Apache Tomcat  
- Maven & Docker  

---

## ⚙️ How to Run
1. Clone repo  
2. Configure database (`hibernate.cfg.xml`)  
3. Run on Tomcat
